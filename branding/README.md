# Bob identity

The name is **Bob**. The mark is a lowercase **b**, white on the existing blue `#1F5FE0`, with one open counter and no gradient. Eric (ElevenLabs premade voice) is the calm male voice. The Android application ID stays `app.saathi` so updates retain settings.

`bob-mark.svg` is the authored vector master. `bob-icon.svg` shows its launcher treatment. Android VectorDrawables use the same path; the adaptive foreground fits the central safe area, with a separate monochrome layer. These production vectors are independently authored geometry, not a cropped AI raster or a font glyph.

`bob-logo-concept.png` was generated with the built-in image_gen tool in logo-brand mode on 2026-11-08, then inspected before implementation. Prompt: A single logo presentation on white: large rounded blue square app icon left with a white unequivocally lowercase b, tall straight left stem and rounded low-right bowl with one blue counter; right blue mark plus lowercase wordmark bob and the same icon at 48 and 24 pixels. One committed concept, flat #1F5FE0, white and #15171C. No gradients, shadows, glow, faces, speech bubbles or uppercase B. Generated source: 01a1bb06-5936-76f0-a275-09a297761bd7/exec-ac14c03e-6127-45c3-b5d0-19317f799c6e.png. The concept includes an exploratory wordmark; only the lowercase b mark ships in the app.

The exact image generation prompt is preserved in `bob-logo.prompt.txt` and embedded in the concept PNG.
