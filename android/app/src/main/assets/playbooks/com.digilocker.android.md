DigiLocker (government documents: Aadhaar, PAN, driving licence, marksheets). Trust the screen over these hints.
- Sign in with mobile number or Aadhaar; an OTP comes by SMS. The senior types the OTP alone: never point at it or read it.
- "Issued Documents" lists documents already fetched. "Search Documents" or the search bar finds new ones (e.g. "Aadhaar", "Driving Licence").
- Fetching a new document asks for details like licence number and then consent; "Get Document".
- Opening a document shows it; there is a download/share option.
