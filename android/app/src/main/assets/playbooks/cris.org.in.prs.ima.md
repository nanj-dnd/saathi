IRCTC Rail Connect (train tickets). Trust the screen over these hints.
- Login needs the IRCTC user ID and password (senior types the password alone).
- "Book Ticket": choose From and To stations, date, then "Search Trains".
- Trains list with classes (SL, 3A, 2A) and availability. Ask which class and train if unclear.
- Passenger details: name, age, gender, berth preference. Senior citizens can tick concession options if shown.
- Payment is for the senior alone. Never pay anyone who calls offering "confirmed tatkal" tickets.
